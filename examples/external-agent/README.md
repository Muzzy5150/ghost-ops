# Independent external agent example

This Node/TypeScript application imports only public `@ghostops/sdk`/`@ghostops/mcp` packages and official SDKs. It never imports Ghost Ops server code, accesses SQLite or reads the signing key. Default mode makes scripted choices with actual guarded MCP tools, **not model inference**.

Build/package in Ghost Ops with `npm run sdk:pack`. Install all three generated tarballs together in a new directory, then run `node node_modules/@ghostops/external-agent-example/dist/main.js --credential-file /absolute/private/identity.json --action normal`. The private credential file is produced by the trusted operator CLI. Alternatively configure identity through `GHOSTOPS_AGENT_ID`, `GHOSTOPS_SESSION_ID`, `GHOSTOPS_AGENT_TOKEN`; `GHOSTOPS_URL` defaults to loopback3210.

Default transport is stdio: this application spawns the protected proxy using a minimal identity environment. `--transport direct` uses SDK → HTTP MCP directly. Actions: `check`, `normal`, `probe`, `poison`, `trap`, bounded `call`, or `session` (persistent newline request driver for integration tests). `normal` reads approved research, writes a summary, retrieves mock status and appends permitted notes. `probe` requests the restricted admin decoy; `poison` ingests untrusted data then requests a protected-policy write; `trap` requests the credential decoy. All denials/effects are real gateway decisions. Console output omits documents and raw tool responses.

Optional `--model --live` requires explicit enablement, provider/model/key in this example's process and interactive exact-run confirmation. OpenAI official SDK only, pinned endpoint, tracing/sensitive logging/retries disabled; 3 calls/turns, 16,000 reported tokens, 600 requested output tokens/call, 8 tools, 60 seconds. These are not guaranteed billing ceilings. Test/CI/noninteractive use is denied. No paid inference ran in verification. External SDK response IDs are **not server-attested provider proof**; the dashboard never upgrades them to VERIFIED PROVIDER. Use the existing Security Lab for persisted transport-backed model evaluations. Model credentials are not passed into the stdio proxy.

`claims.js` is a fixed synthetic negative-test actor for forged headers/unsupported memory-owner fields. It calls only the protected local MCP endpoint; it executes no unguarded effects. Physical browser checks remain pending.

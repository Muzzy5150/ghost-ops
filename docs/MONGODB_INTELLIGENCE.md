# Optional incident intelligence index

Official `mongodb@7.7.0` performs stable namespace-qualified upserts and bounded metadata/text retrieval. No actual MongoDB server was contacted. Enable only with explicit synthetic-data permission: `GHOSTOPS_SPONSOR_EGRESS=1`, `GHOSTOPS_MONGODB_ENABLED=1`, private `GHOSTOPS_MONGODB_URI`, matching `GHOSTOPS_MONGODB_APPROVED_HOST`. Remote connections require TLS or mongodb+srv. This initial URI validator supports a single hostname; multi-host custom URI layouts are not promised.

Sponsor Integrations → index → inspect/confirm sends at most 100 incidents with at most 1000 event references each. Fixed database ghostops_intelligence / incidents uses a sourceNamespace/agentId/updatedAt index. Search uses an escaped literal query, 50 matches, bounded network/query timeouts; not a caller-defined Mongo query. Server validates returned namespace/source/evidence IDs against SQLite and regenerates displayed summaries from authoritative records. Summaries/counts/IDs only leave the host; raw narratives, credentials, prompts, memory contents and signatures do not.

Search results cannot grant permissions or directly execute response actions. Index lag is explicit. Stable _id makes repeated indexing idempotent; uncertain network delivery is not retried automatically. Missing or mismatched source references fail the action. Explicit TLS/SSL downgrade (including SRV) and certificate/hostname-verification bypass options reject configuration. No Vector Search, embeddings, semantic similarity claims, cloud account or production migration. Mongo outage cannot block local gateway authorization.

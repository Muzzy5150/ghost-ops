# Ghost Ops developer SDK

`@ghostops/sdk` 0.1.0 is a Node.js 22.12+ ESM TypeScript package. Declarations and stable public exports ship in `dist`. It supports authenticated MCP initialization/discovery/calls to a **plain HTTP loopback origin**, not arbitrary remote services. Nothing is published to npm.

## Build and install

From GhostOps: `npm ci && npm run sdk:pack`. This creates `ghostops-sdk-0.1.0.tgz`, `ghostops-mcp-0.1.0.tgz` and `ghostops-external-agent-example-0.1.0.tgz`. Root npm workspaces link the public packages for local example commands; the acceptance test independently installs tarballs outside the repository.

In your own project, install the SDK tarball with `npm install /absolute/path/GhostOps/ghostops-sdk-0.1.0.tgz`. For stdio and the complete example, install all three tarballs in the same command so their local versioned dependencies resolve without registry publication. `npm run test:external` verifies that installation automatically.

```ts
import { GhostOpsClient, GhostOpsError } from '@ghostops/sdk';

const ghost = new GhostOpsClient({
  endpoint: process.env.GHOSTOPS_URL!, // http://127.0.0.1:3210
  agentId: process.env.GHOSTOPS_AGENT_ID!,
  sessionId: process.env.GHOSTOPS_SESSION_ID!,
  credential: process.env.GHOSTOPS_AGENT_TOKEN!,
  timeoutMs: 10_000,
  logger: entry => console.log(entry), // only safe event/code/ID/allowed metadata
});
try {
  const approvedTools = await ghost.listTools();
  const decision = await ghost.callTool({
    tool: 'read_document', arguments: { resource: 'docs/research' },
  }, { signal: AbortSignal.timeout(5_000) });
  // Use decision.output as data locally; do not indiscriminately log outputs.
  void approvedTools; void decision;
} catch (error) {
  if (error instanceof GhostOpsError) console.error(error.toJSON());
} finally { await ghost.close(); }
```

## API

`connect`, `listTools`, `requestTool`, `callTool`, `close`. Discovery reconnects/checks the server; it is not cached authorization. `requestTool` returns a strict `{requestId, allowed, reason, output, incidentId, replayed}` decision; `callTool` throws on denial and exposes the same decision. Allowed operations execute only at the existing server handler. Public exports also include `decisionError`, `endpointOrigin`, `validateTool`, catalogs, strict schemas and associated TypeScript types.

Tools: `read_document`, `list_tasks`, `write_summary`, `operational_status`, `read_memory`, `write_memory`, `restricted_admin`. Resources are fixed synthetic aliases, not filenames/URLs. Protected-memory and decoy operations can be explicitly requested for evaluation, but are not granted simply because they are in this validation catalog. Discovery advertises only names with a currently permitted resource; **it does not grant every resource accepted by that tool's input schema**. Server policy checks every call.

Writes require 1–4000 characters, reads reject content. JSON requests have a 16 KiB byte cap and responses a 64 KiB cap, including error bodies. Endpoint URLs cannot include credentials, path, query or fragment and must use `127.0.0.1`. Identity/owner/provenance extras in tool arguments are rejected. No general event-ingestion method is exposed: trustworthy telemetry is generated by authenticated gateway execution, not caller assertions.

## Errors, cancellation and delivery

Codes: `AUTHENTICATION_FAILED`, `PERMISSION_DENIED`, `AGENT_QUARANTINED`, `CREDENTIAL_REVOKED`, `GATEWAY_UNAVAILABLE`, `INVALID_REQUEST`, `REQUEST_TIMEOUT`, `CANCELLED`, `UNSUPPORTED_OPERATION`, `REQUEST_CONFLICT`, `TOOL_FAILED`. Unknown transport errors become sanitized errors; raw exceptions, headers and credentials are not logged. Do not stringify complete application objects containing your own secrets.

Each client is **single-flight**; await operations in sequence. Concurrent calls fail rather than creating an unbounded queue. Per-operation `AbortSignal` and `timeoutMs` (1–30000 ms, default 10000) reach actual HTTP fetch. Cancellation/timeout after dispatch cannot undo committed effects. Errors retain the generated request UUID after uncertain delivery. You may deliberately retry the **exact UUID/input**; never retry mutations automatically. Modified reuse conflicts. Exact replay rechecks present authority, executes no second handler and returns minimized historical receipts without old output. Revocation/quarantine can invalidate a formerly allowed replay.

No administrative methods, self-provisioning, model verification receipts, shell/filesystem executors, remote MCP routing or universal OS interception. See [security boundary](PHASE8_SECURITY_MODEL.md) and [quickstart](EXTERNAL_AGENT_INTEGRATION.md).

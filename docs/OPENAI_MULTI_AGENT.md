# Explicitly approved specialist model runs

Open Sponsor Integrations → model-org → choose normal/prompt-injection/memory-poisoning → optionally specify an approved context ID → Inspect exact action → inspect provider/model, per-agent budgets, aggregate maximum calls/tokens and 180-second organization deadline → confirm. Missing model configuration disables execution. Opening/preflighting never calls a model.

Server shell configuration (never put real keys in source/chat): `GHOSTOPS_MODEL_ENABLED=1`, `GHOSTOPS_MODEL_PROVIDER=openai`, `GHOSTOPS_MODEL=<exact-approved-model>`, `OPENAI_API_KEY` supplied privately. The server must be restarted only on its isolated port to change environment. Next .env handling differs from CLI scripts; explicit shell configuration is easiest to audit.

Compatible local Responses endpoint: `GHOSTOPS_MODEL_PROVIDER=local-responses`, `GHOSTOPS_MODEL_BASE_URL=http://127.0.0.1:PORT/v1`, approved model identifier, and a private `GHOSTOPS_LOCAL_MODEL_KEY` or explicit `GHOSTOPS_LOCAL_MODEL_ALLOW_NO_AUTH=1`. Chat-Completions-only servers are NOT supported. No model is downloaded. A completed local-compatible response remains **unverified inference**: Ghost Ops cannot prove an arbitrary local endpoint used a genuine model instead of returning a stub.

Research/Coordinator/Operations get fresh distinct credentials/sessions/grants and an explicit synthetic Hunt scope. Each runs the official Agent/Runner and chooses its own bounded tools. Production model tools use authenticated local HTTP MCP, never direct filesystem access. Only Research/Coordinator have bounded summary/notes/delegation capabilities; Operations has status/inbox only. If a model never submits a message, downstream agents report no received delegation rather than fabricating it.

Defaults per role: at most 3 model calls, 12 tool calls, 16,000 reported tokens, 600 requested output tokens/call, 60 seconds. Aggregate preflight shows three times the per-role call/token limits, with a 180-second organization deadline. Budgets can be supplied through the strict authenticated API; input reservation/accounting cannot guarantee a provider billing ceiling. No retries, tracing, provider storage request, raw prompts or private reasoning logging. Unknown usage stops further inference. Public output is hashed; resistance is only an explicit observable public refusal following an actual untrusted read, never assumed from absence of denial.

Receipts record role/identity/session/provider/requested model, actual invocation/response metadata, usage where supplied, policy decisions and verified-call count. Model-organization receipts live in IntegrationRun; existing Lab ModelInvocation records remain intact. Successful genuine OpenAI transport responses can qualify as verified provider; mock adapters and scripted choices never do. No genuine OpenAI inference was executed in Phase 11. Cancellation acts at safe boundaries; an already dispatched request may finish/incur charges. Restart marks uncertain runs interrupted, never resumes them. Fresh scopes default observe; model text cannot administer containment.
